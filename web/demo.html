Repo Expert — demo local

Banco de pruebas del cliente de chat. La página real vive en el sitio.

Sírvela por HTTP, no con file://: el origen null no está en CORS_ORIGINS. Con un servidor local en el puerto 5500 (python -m http.server 5500) el origen sí está permitido. Límite: 10 preguntas/hora por IP — la 11ª devuelve 429. Cada pregunta es independiente: la API no guarda historial de conversación.
